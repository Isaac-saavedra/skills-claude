# Contribuir

1. Crea una rama para el cambio.
2. Mantén cada Skill enfocada en una tarea clara.
3. Actualiza `SKILL.md` y referencias relacionadas.
4. Comprueba el frontmatter, nombre y descripción.
5. Añade ejemplos que reflejen casos reales sin datos sensibles.
6. Ejecuta `python3 scripts/validate_skills.py`.
7. Describe el cambio, motivación, pruebas y limitaciones en el pull request.

No incluyas secretos, datos personales ni instrucciones para acciones no autorizadas.
